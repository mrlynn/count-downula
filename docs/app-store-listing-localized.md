# App Store listing: localized drafts

Status: drafts, October 9, 2026. Each needs a native reviewer before it goes into App Store Connect, the same as the app's String Catalog. They translate the English listing in [app-store-listing.md](app-store-listing.md) as it stands; when that changes, these need the same change.

The name stays **Count Downcula** everywhere. Keywords aren't translations of the English list: each is what people in that market type, without words already in the name or subtitle. The limits are Apple's: subtitle 30, promotional text 170, keywords 100, description 4,000. `scripts/check-listing-lengths.py` measures them.
